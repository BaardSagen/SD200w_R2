SAIV Instrument Terminal 1.4.3
Released: 9 September 2026

WHAT IS NEW
The update window now explains how to check manually or restore the startup
message after selecting "Do not check for updates at startup":

Use Help > Update software to check for updates manually
or turn this startup message back on.

No changes to instrument communication, calculations, graphs or installation.

NEW USERS
Download the ZIP, extract it and run the EXE. No earlier version is required.
Supporting components are embedded and prepared automatically.

EXISTING USERS
In version 1.4.1 or later, use Help > Update software > Check now.
Save your work and finish instrument operations before confirming installation.
The existing filename and location are kept, with a backup of the earlier EXE.
