# Last opp SIT 1.4.10

Last opp disse tre filene til `https://saiv.no/software/`, i denne rekkefølgen:

1. `SAIV_Instrument_Terminal_v1.4.10_Sept2026.zip`
2. `README_v1.4.10.txt`
3. `latest.json` – last opp denne sist og erstatt serverens eksisterende fil.

Behold navnene nøyaktig. `latest.json` gjør oppdateringen synlig for kundene og inneholder kontrollsummen for ZIP-filen.

ZIP-filen inneholder én EXE, README.txt og lisensnotater. Eksisterende brukere fra 1.4.1 kan velge Help > Update software > Check now. Nye brukere kan pakke ut ZIP-filen og starte EXE-filen direkte.

Tidligere pakker er beholdt. `latest_v1.4.3.json` er en lokal historisk kopi og skal ikke erstatte den nye `latest.json` ved opplasting. Dette instruksjonsnotatet trenger heller ikke lastes opp.

Pakken er klargjort lokalt. Serveren er ikke endret av oss.
