SAIV Instrument Terminal 1.4.1
Released: 9 September 2026

WHAT IS NEW

Software update checks
- At startup, SAIV IT asks before contacting the update server.
- Select "Do not check for updates at startup" to stop this prompt.
- Help > Update software lets you check manually or change that preference.
- The update window shows your installed version and the server version.
- Read the release notes before deciding whether to install an update.

Automatic installation after confirmation
- Choose Install update and confirm when you are ready.
- Save your work and finish instrument operations first.
- The download and its checksum are verified before SAIV IT closes.
- The EXE is replaced in its existing location, with the same filename.
- A backup of the previous EXE is kept beside it as a .previous-<number>.bak file.
- SAIV IT starts again, so your existing shortcut continues to work.
- Windows asks for administrator permission only if the folder requires it.
- If Windows prevents automatic restart, start the program using your normal shortcut.

SHOULD I UPDATE?
Install 1.4.1 if you want release notifications and easier future updates.
It also includes the import, graph, interval and clock improvements from 1.4.0.

FIRST UPGRADE
Versions 1.4.0 and earlier do not contain this update feature. Install 1.4.1
manually once. Subsequent updates can be installed from within the program.
Extract the ZIP and run SAIV_Instrument_Terminal_v1.4.1_Sept2026.exe.
The supporting components are embedded and prepared automatically.

Your measurement files and saved settings are not moved by the updater.
An older server version is never offered as an automatic downgrade.
