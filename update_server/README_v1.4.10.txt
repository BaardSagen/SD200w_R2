SAIV Instrument Terminal 1.4.10
Released: 10 September 2026

WHAT IS NEW SINCE 1.4.3

QUICK GUIDE
Help > Quick guide provides 26 offline topics covering instrument operation,
files, conversion methods, measurement units and practical examples.
The guide explains that SD208 calculates salinity S from conductivity,
temperature and pressure using PSS-78. S is also called SP in scientific
references. Instrument salinity and recalculation in Convert are explained
separately. The About window now uses the current SAIV instrument icon.

CONVERSION CHOICES
Convert offers SIT PSS-78 and GSW PSS-78/Hill salinity, Absolute Salinity,
temperature-scale choices, pressure-to-depth methods, density and sound-speed
models, and oxygen concentration methods and units.
Relevant help is available directly from the conversion pages.
Selected methods and supporting values are recorded in the exported file.
Original measurement columns can be retained alongside calculated results.
The new method choices apply to Convert; other calculation menus keep their
existing methods.

FILES
Convert also accepts older CTD/STD text with Date/Time and Interval headers.
Times reconstructed from these headers are identified in the output.
Converted fields are retained when importing to SD2 and reopening the dataset;
keep all companion files together.

NEW USERS
Extract the ZIP and run the EXE. No earlier version is required.
Supporting components and calculation data are embedded and prepared
automatically. No separate DLL installation is required.

EXISTING USERS
In version 1.4.1 or later, use Help > Update software > Check now.
Save your work and finish instrument operations before confirming installation.
The existing filename and location are kept, with a backup of the earlier EXE.
Versions before 1.4.1 require a manual first upgrade.
