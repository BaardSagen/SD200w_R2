SAIV Instrument Terminal 1.4.12
28 October 2026

CONVERT MULTIPLE FILES
Select several TXT/CSV files with Ctrl or Shift in Convert, then choose
an output folder. Calculation choices are reused for matching file layouts.
GPS and missing measurement conditions are requested for each file as needed.
Each file gets a separate _SIT.txt export. Original files and existing
exports are kept. A progress window shows results and lets you cancel
remaining files. Selecting one file keeps the table and graph workflow.

FIRMWARE FOR HARDWARE 3.1.2 AND 3.3.0
Help > Firmware supports OSU107 and SAIV110 with either hardware revision.
SIT checks the device hardware and automatically selects the matching
firmware from saiv.no. A mismatched firmware variant is rejected.

INSTALLATION
New users: extract the ZIP and run the EXE. No separate DLL is needed.
Existing users with version 1.4.1 or later: use Help > Update software.
Save your work and finish instrument operations before installing.
