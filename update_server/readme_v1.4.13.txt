SAIV Instrument Terminal 1.4.13
28 October 2026

FIXED: TIME/DATE AND INTERVAL
TIME/DATE and Interval now open their correct device settings windows.
In 1.4.12, these buttons could incorrectly open the Convert file picker.

Multiple-file conversion and Merge are retained. Select several TXT/CSV
files with Ctrl or Shift in Convert and choose an output folder.

Help > Firmware retains automatic selection of the matching firmware for
OSU107 and SAIV110 hardware 3.1.2 or 3.3.0.

INSTALLATION
New users: extract the ZIP and run the EXE. No separate DLL is needed.
Existing users with version 1.4.1 or later: use Help > Update software.
Save your work and finish instrument operations before installing.
