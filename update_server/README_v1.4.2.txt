SAIV Instrument Terminal 1.4.2
Released: 9 September 2026

UPDATE TEST RELEASE

This release has the same features as version 1.4.1.
The version number has been increased so you can test the complete update
from 1.4.1: release notes, confirmation, download, installation and restart.
There are no changes to instrument communication, conversions or graphs.

NEW USERS
You can use this release directly without installing an earlier version.
Download the ZIP, extract it and run the EXE. Supporting components are
embedded and prepared automatically at first startup.

HOW TO TEST
Start version 1.4.1 on your PC and choose Help > Update software.
Choose Check now. When 1.4.2 appears, read these notes and choose Install update.
Save your work and finish instrument operations before confirming.

The program keeps its existing location and filename, creates a backup of
the previous EXE and restarts. The filename may still contain 1.4.1;
check the installed version in Help > Update software or the About window.
It should now show 1.4.2.

This is an optional update intended to verify the update process.
