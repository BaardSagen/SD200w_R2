## Changes since 0.9.9A

### 0.9.9B: configurable storage separators

- Added the configured `separator` behavior to both schedule and instrument storage.
- Compact mode uses the same separator in `FIELDS:` and data rows.
- Full mode keeps the original space-separated output when `separator` is empty.
- A non-empty full-mode separator, for example `;`, separates the existing prefixed
  measurement tokens; full mode does not add a `FIELDS:` row.
- Existing OSU, date, instrument-mode, and schedule headers remain in the stored file.

### 0.9.9C: dynamic compact TIMEBASE

- Compact instrument and schedule logging now buffer the first rows until a stable
  cadence is confirmed from two consecutive counter/time gaps.
- The stored time base identifies the first stable row explicitly, for example:
  `TIMEBASE: FROM_COUNT=2 TIME=10:51:35 INTERVAL_S=2`.
- Startup delay in `N1`/`S1` therefore no longer makes compact timestamps ambiguous.
- The interval comes from the instrument header or schedule configuration and is not
  inferred from an incomplete startup sequence.
- `FIELDS:` and the buffered rows are written immediately after `TIMEBASE:` once the
  cadence is confirmed. Short/incomplete series still retain the configured interval.
- Hardware verification on `SN107` confirmed dynamic time base in both instrument and
  schedule compact files, including semicolon-separated rows.

### 0.9.9D: wake recovery after passive/menu timeout

- Normal inactivity and an open COM port do not intentionally disable instrument wake.
- Fixed a possible permanent `I` block if the final `- passive -`/wake-prompt text was
  lost while an interactive instrument-menu latch was active.
- Stale instrument-menu state now expires after 15 seconds before a new wake `I`.
- MAX3222 force-enable time was increased from 10 to 15 seconds, providing margin past
  the SD204/8 instrument's own 10-second automatic menu transition.
- Machine verification covered:
  - COM11 open and idle for 35-45 seconds before held-`I` wake
  - `CFG-APPLY`, then 35 seconds idle on the same open COM connection, then wake
  - automatic start, stop with `I`, automatic passive after 10 seconds, and a new wake
  - all tests completed without USB replug or OSU reset
- A short single `I` byte is not a complete wake command; the SD204/8 prompt requires
  holding `I`. Extra held characters are blocked once instrument menu output begins.

## Calibration and ADR4525 reference work

- ADR4525/REFOUT ratio measurements now use a shared ADR4525 power/warmup helper.
- ADR4525 warmup is 4 seconds before the ratio read.
- The helper feeds the watchdog during warmup.
- INTREF/REFCHECK power ADR4525 only for the check and turn it off again afterwards.
- Implausible ADR4525/REFOUT ratios are rejected before calibration data is written.
- `INTREF.CAL` stores both:
  - `intref_ratio_cal`
  - `intref_cal_temp_c` and `intref_cal_temp_uv`
- mvProvision timeout/menu handling was extended so production calibration can survive the longer ADR4525 warmup.

## New manual calibration verification

- New local menu option: `<V> Verify calibration`.
- Available in both:
  - schedule-logger menu
  - instrument OSU-107 option menu
- The check reads ADR4525/REFOUT ratio and ADS1263 internal temperature.
- It compares current ADS temperature to stored `adc_core.intref_cal_temp_c`.
- It only judges ratio drift if temperature is within `+/-2.0 C` of the calibration temperature.
- It recommends recalibration if ratio drift exceeds `+/-500 ppm`.
- Schedule mode blocks the check while schedule-logger is running, because ADS/mux must not be shared with an active measurement.

## Power and mux fixes already in the current line

- U8/ADG708 mux power path is now explicitly enabled for ADS single/reference checks.
- This fixed the issue where channels followed the previous/channel-0 value when U8/opamp power was not properly on.
- Sensor power warmup for normal runtime/schedule measurement intervals over 2 seconds uses a minimum 2 second prewarm on every measurement, not only the first one.
- Rinko oxygen calibration keeps sensor power on across its repeated calibration samples and waits before the first read.

## Menu changes

- Zero tilt is available as `<Z>` in schedule and instrument OSU options.
- Calibration verify is now `<V>` in schedule and instrument OSU options.
